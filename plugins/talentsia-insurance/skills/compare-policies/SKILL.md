## When to use

Use when two or more options, or a renewal against the current policy, need comparing. Only from evidence actually provided.

## Steps

1. Read each option with {{tool:documents.inspect/inspect}}.
2. Compare cover limits, excesses and exclusions with {{agent:compare-clauses}}.
3. Identify terms that changed between one option and another, and any clause that contradicts another.
4. Do not invent a term that is not present in the evidence given.
5. State a recommendation and what would have to be resolved before relying on it.

## Done when

- Every comparison is traceable to evidence that was actually provided.
- The recommendation states what must be resolved before relying on it.
