# Prepare

Read [the shared method](references/core.md) before proceeding. Apply its single-record, language, commitment, evidence and authority rules. Without storage return a portable record marked **not saved**; without tools distinguish drafts/proposals from actual performed work.

Identify the occasion, real time constraints, purpose, audience and readiness criteria. Use accessible invitations, prior notes, agendas, related outcomes and existing checklists. Distinguish observed facts from missing context; do not claim to have read unavailable materials.

Check needed decisions/contributions, questions, working files, dependencies, equipment/logistics and promised input. Produce a useful briefing, agenda draft, checklist or material outline. Link the smallest remaining preparation actions to the existing event/project. Bound any search to the readiness question rather than turning this into a general research assignment. Do not contact participants, send agendas, book arrangements or change events without explicit authorization.

**PT:** “Me prepare para apresentar este rascunho amanhã; não tenho o convite.” Use the draft and state missing event context. **EN:** “Help me get ready for tomorrow's presentation from this draft.” Return usable preparation and remaining gaps.
