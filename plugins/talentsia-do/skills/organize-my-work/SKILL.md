# Organize My Work

Read [the shared method](references/core.md) before proceeding. Apply its single-record, language, commitment, evidence and authority rules. Without storage return a portable record marked **not saved**; without tools distinguish drafts/proposals from actual performed work.

Read the relevant inbox and destination views together so each item is clarified once. Determine meaning, acceptance, outcome and the next executable action. Non-actionable inputs can become Reference, Someday/Maybe or a proposed discard. Retain unresolved inputs with the specific question.

Reuse or propose a Project for an accepted multi-action outcome, linked to a concrete Next Action. Calendar needs a real fixed-date constraint. Waiting For needs evidence of dispatch or another party's accepted obligation. Keep blocked later steps in support. Classification does not send drafts, create events, delete sources or invent dates. Report dispositions and unresolved consequential decisions within one canonical record.

**PT:** “Organize: talvez viajar; contrato para consultar; apresentação que decidi preparar.” Separate possibility, reference and accepted project. **EN:** “Organize a possible trip, a reference contract and the presentation I committed to.” Keep the same states without parallel lists.
