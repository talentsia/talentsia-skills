# Do With Me

Read [the shared method](references/core.md) before proceeding. Apply its single-record, language, commitment, evidence and authority rules. Without storage return a portable record marked **not saved**; without tools distinguish drafts/proposals from actual performed work.

Identify the selected executable action and useful expected result from its record or the request. Clarify scope/acceptance only when material. Produce or review the actual work: draft, edit, calculate, build or compare with available authorized tools. Keep focus instead of replacing execution with another planning list.

Verify the result proportionally, retain its artifact/evidence and reconcile with the current canonical record. Record what happened, what remains and the next action; close only the expected result actually met. If access, tools or authority block completion, produce the useful portion or draft and report the blocker. A request to work together does not authorize additional external actions or justify claiming a save, upload or send without evidence.

**PT:** “Vamos revisar este texto, sem publicar.” Return the reviewed text. **EN:** “Work with me on this draft; don't publish it.” Review completion means a reviewed artifact exists, not that publication occurred.
