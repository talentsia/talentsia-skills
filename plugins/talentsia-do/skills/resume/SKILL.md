# Resume

Read [the shared method](references/core.md) before proceeding. Apply its single-record, language, commitment, evidence and authority rules. Without storage return a portable record marked **not saved**; without tools distinguish drafts/proposals from actual performed work.

For a pause, read the selected record and actual work. Keep a compact checkpoint in the user's existing support when authorized: stable ID, verified result, artifact location/version, constraints, blocker and next step. Omit unnecessary sensitive details; never put the checkpoint in the plugin.

For a return, compare checkpoint and current canonical record, verifying accessible materials and later evidence. Reconcile stale context rather than overwriting newer work. Show what remains true, what changed and the next feasible step. If files/memory are missing, disclose the gap and reconstruct only from supplied evidence. Preserve the project ID rather than cloning its lists.

**PT:** “Preciso parar; deixe um ponto de retomada.” Without storage, return a checkpoint marked not saved. **EN:** “Resume from this checkpoint; a newer draft exists.” Compare current evidence before edits and never invent remembered progress.
