# Talentsia Recruiting

Staffing an organisation: diagnosing what is really missing, designing a seat and its procedures, and preparing one decision a person can answer.

Free, basic edition for Talentsia Edge workers. MIT licensed. The contract these skills follow is [docs/edge-worker-skills.md](../../docs/edge-worker-skills.md); validate with `python3 scripts/check_edge_skills.py`.

| Skill | What it does | Replaces |
|---|---|---|
| [`diagnose-staffing-demand`](skills/diagnose-staffing-demand/SKILL.md) | Turn promises nobody can keep into a named gap per area, and say which of them is actually a seat. | `diagnose_staffing_demand` v1 |
| [`design-a-seat`](skills/design-a-seat/SKILL.md) | What a position must be able to do, what must exist before anybody could fill it, and how its first piece of work will be judged. | `design_a_seat` v1 |
| [`design-a-procedure`](skills/design-a-procedure/SKILL.md) | Write the steps that turn a seat into a worker that does the work the same way twice. | `design_a_procedure` v1 |
| [`prepare-a-staffing-decision`](skills/prepare-a-staffing-decision/SKILL.md) | Do everything up to the point where only a yes or a no is left, one seat at a time. | `prepare_one_staffing_decision` v1 |
