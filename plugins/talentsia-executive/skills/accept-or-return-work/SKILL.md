## When to use

Use when a colleague's deliverable comes back to you. A reply is judged here, never handed on again.

## Steps

1. Read the work itself with {{tool:artifacts.read/read}}, and how it was done with {{tool:work.history.read/activity}}. Never judge a deliverable by its title.
2. Compare it with the brief using {{agent:check-against-brief}}.
3. If it meets the brief, record that with {{tool:artifacts.dispose/dispose}}, naming who or what now uses it.
4. If it is nearly there, accept it and record what is still missing as its own promise or handover. Never send a whole piece back for one gap.
5. If it does not meet the brief, record it as rejected with the one thing that must change, and hand it back with {{tool:work.handoff/delegate}}.
6. Where it says what it could not establish, answer it, hand it to somebody who can, or put it to a person.
7. Leave a deliverable waiting for a person's decision alone: that judgement is theirs.

## Done when

- Every deliverable you judged carries a recorded disposition.
- Any rejection names the single thing that must change.
- Nothing is accepted on the strength of what the answer said about itself.
