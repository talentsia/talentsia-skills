# Talentsia Executive

Running an area of the organisation: moving its promises, briefing specialists, judging what comes back and naming what the area cannot do.

Free, basic edition for Talentsia Edge workers. MIT licensed. The contract these skills follow is [docs/edge-worker-skills.md](../../docs/edge-worker-skills.md); validate with `python3 scripts/check_edge_skills.py`.

| Skill | What it does | Replaces |
|---|---|---|
| [`run-a-vertical`](skills/run-a-vertical/SKILL.md) | A pass over your own area: read what is owed and in flight, put each piece of work with whoever can do it, put judgements in front of a person, and name what the area cannot do. | `run_a_vertical` v1 |
| [`brief-a-specialist`](skills/brief-a-specialist/SKILL.md) | Write the brief that goes with a handover, so the worker receiving it can finish without coming back to ask what was meant. | `brief_a_specialist` v1 |
| [`accept-or-return-work`](skills/accept-or-return-work/SKILL.md) | Read what came back against what was asked, and record which it is: accepted, accepted with what is still missing, or returned with the one thing that has to change. | `accept_or_return_work` v1 |
| [`name-the-gap`](skills/name-the-gap/SKILL.md) | When nobody in your area can do the work: decide which of five gaps it is, and ask for a seat only when it is capacity or a missing trade. | `name_the_gap` v1 |
